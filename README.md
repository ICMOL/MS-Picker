# MS-Picker

## Introduction
MS-Picker is a software tool implemented for detecting peaks from either proteomics or metabolomics data sets generated by LC-MS/MS. For metabolomics data sets, it performs noise removal, de-isotoping, and extracted ion chromatogram (XIC) construction as the algorithms described in [請 cite iMet-Q], exporting the m/z, retention time, charge states and intensities of detected peaks. On the other hand, for proteomics data sets,, the algorithm of theoretical isotope pattern generation described in [ref, 是在哪一篇文章?] is additionally implemented in MS-Picker for accurate charge state determination.

## System Requirement
* [Java SE Runtime Environment 15(or above)](https://www.oracle.com/java/technologies/javase/jdk15-archive-downloads.html)

## Parameter Description
|parameter|description|
|omics_index| the index for indicating if the input is a proteomics dataset or a metabolomics dataset. 0: metabolomics; 1: proteomics|
|mzTol| the m/z tolerance for detecting a peak|


## How to Use (請將你的command改成下列格式)
* java -jar MS-Picker input_files output_folder omics_index mzTol
* (for a single file) java -jar MS_Picker.jar D:\test.mzML D:\output_folder 0 0.02
* (for multiple files) java -jar MS_Picker.jar D:\*.mzML D:\output_folder 0 0.02
