# Introduction
MS-Picker is a software tool implemented for detecting peaks from metabolomics datasets generated by the LC-MS/MS platform. Our software tool performs noise removal, de-isotoping, and extracted ion chromatogram (XIC) construction as the algorithms described in [1], exporting the m/z, retention time, charge states and intensities of detected peaks.

## ***MS-ToolBox***
We proposed a comprehensive platform with four implemented software tools, including [MS-Picker](https://github.com/ICMOL/MS-Picker.git), [MS-Point](https://github.com/ICMOL/MS-Point.git), [MS-Aligner](https://github.com/ICMOL/MS-Aligner.git), and [DeNox](https://github.com/ICMOL/DeNox.git), as important components for metabolomics quantitation. [MS-Picker](https://github.com/ICMOL/MS-Picker.git) is a software tool implemented for detecting peaks from metabolomics data sets generated by the LC-MS/MS platform. [MS-Point](https://github.com/ICMOL/MS-Point.git) is a cross-platform command-line tool that applies logistic regression using nine quality metrics to assess peak quality, generating a quality score for each detected peak. [MS-Aligner](https://github.com/ICMOL/MS-Aligner.git), another command-line tool, facilitates peak alignment based on the output from MS-Point. Finally, [DeNox](https://github.com/ICMOL/DeNox.git) provides visualization capabilities applicable to both proteomics and metabolomics data, offering features such as an elution heatmap, extracted ion chromatogram, spectrum information, and nine metrics for peak quality assessment. Together, these tools form a cohesive platform for comprehensive metabolomics quantification.

# System Requirement
* [Java SE Runtime Environment 15(or above)](https://www.oracle.com/java/technologies/javase/jdk15-archive-downloads.html)

# Parameter Description

|parameter|description|
| ------------- | ------------- |
|mzTol| The m/z tolerance for detecting a peak.|
|input_file| The location of mzML files to be processed.|
|output_folder| The location of output files (a peak list corresponds to an mzML file.|


# How to Use
* **For a single mzML file**
<blockquote>
    java -jar MS-Picker.jar mzTol output_folder input_file<br>
    <blockquote>
    e.g., java -jar MS-Picker.jar 0.02 D:\output_folder D:\test1.mzML
    </blockquote>
</blockquote>
    
* **For mltiple mzML files**
<blockquote>
    java -jar MS-Picker.jar mzTol output_folder input_file1 input_file2 input_file3<br>
    <blockquote>
    e.g., java -jar MS-Picker.jar 0.02 D:\output_folder D:\test1.mzML D:\test2.mzML D:\test3.mzML<br>
    </blockquote>
    java -jar MS-Picker.jar mzTol output_folder input_folder_path\*.mzML<br>
    <blockquote>
    e.g., java -jar MS-Picker.jar 0.02 D:\output_folder D:\*.mzML
    </blockquote>
</blockquote>
