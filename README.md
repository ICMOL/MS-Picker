# Introduction
MS-Picker is a software tool implemented for detecting peaks from metabolomics data sets generated by the LC-MS/MS platform. Our software tool performs noise removal, de-isotoping, and extracted ion chromatogram (XIC) construction as the algorithms described in [1], exporting the m/z, retention time, charge states and intensities of detected peaks.

![image](https://github.com/ICMOL/MS-Picker/blob/main/MS-Picker%20workflow_ver4.0.jpg)
Figure 1. The workflow of MS-Picker, including nosie remal, deisotoping, extracted ion chromatogram construction, and charge state determination.

# System Requirement
* [Java SE Runtime Environment 15(or above)](https://www.oracle.com/java/technologies/javase/jdk15-archive-downloads.html)

# Parameter Description

|parameter|description|
| ------------- | ------------- |
|mzTol| The m/z tolerance for detecting a peak.|
|input_folder| The location of mzML files to be processed.|
|output_folder| The location of output files (a peak list corresponds to an mzML file.|

* The input_folder should only contain the mzML files to be analyzed. (在程式中設定只取 mzML 檔案)

# How to Use
* java -jar MS-Picker mzTol output_folder input_folder (將 input_folder, output_folder 對調)
* java -jar MS_Picker.jar 0.02 D:\\output_folder D:\\input_folder
